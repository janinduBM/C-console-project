Assignment 2 - Guidelines
IN 1101 - Programming Fundamentals
1. Project Overview
Students must develop a console-based C application as a group project. Each group should
consist of 5 members. The application must be based on a real-world scenario. The selected
system should solve a meaningful real-world problem, not just display simple outputs or unrelated
functions.
2. Main Requirement
Each group must design a system where all 5 members contribute equally.
To ensure fair contribution:
• Each member must be responsible for one major module of the system.
• Each member must define and use at least one structure.
• Therefore, the full project must contain at least 5 structures.
• Each member must implement at least 5 logical functions related to their module.
• The system must have a menu-driven interface in the main() function.
• Functions must be logically connected to the selected real-world system.
The project must include:
1. At least 5 structures
2. At least 25 logical functions in total (5 members × 5 functions each = 25 functions)
3. Menu-driven interface using switch
4. Separate functions for logical activities
5. Arrays of structures
6. String handling where necessary
7. Proper input and output handling
8. Meaningful real-world data
9. Clear comments in the code
10. Individual contribution clearly shown
Students may improve their project by using:
• Pointers
• Arrays
• String functions
• Nested structures
• Passing structures to functions
• Passing arrays of structures to functions
• Sorting and searching
• Validation of user input
• Clearly specify each member’s contribution in the report.
Your group must submit a short report including:
• Project Title
• Group Members and Individual Contributions
• System Overview
• Programming Concepts Used
• Screenshots of Outputs
• Challenges Faced and Solutions
• Conclusion
Report Submission Deadline: 02-June-2026 11:59 p.m
Presentation:
• Each group will present and demonstrate the application physically on the scheduled date.
• Each member must present their own part.
• You will only get 10 minutes for the presentation and 5 minutes will be allocated for the
Q&A.
